# Sam Vu · Portfolio

**Live:** [dangvu3627.github.io](https://dangvu3627.github.io/)

My personal portfolio. I'm a Computer Science (Co-op) student at the University of Waterloo, writing embedded flight software at the Waterloo Aerial Robotics Group (WARG).

The site brings together my experience, projects and technical skills in embedded systems and hardware, from STM32 firmware and CAN logging to a flight-tested Arduino quadcopter, so recruiters and collaborators can find what I work on and how to reach me.

## Concept

The page is styled as a drone camera feed. It opens by powering up the drone's view: the field-of-view frame comes online, telemetry flickers in, the horizon and crosshair calibrate, then the reticle locks onto me as the target. From there, the HUD bar tracks which section you are in as you scroll. The HUD theme stays in the frame and the motion, while the content reads like a clear, recruiter-friendly resume.

## What's inside

- **Intro:** who I am, my degree and my scholarship, right in the opening view
- **Experience:** embedded flight software at WARG and robotics team leadership
- **Projects:** hardware and software builds, each linked to its source
- **Skills:** languages, microcontrollers, protocols, embedded concepts, hardware and tools
- **Contact:** email, GitHub and LinkedIn

## Built with

Astro and TypeScript with plain CSS, as a fast, static, accessible single page.
